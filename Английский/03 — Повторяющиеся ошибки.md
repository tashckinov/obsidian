# Повторяющиеся ошибки

Здесь храним не все ошибки подряд, а только те, которые повторяются или показывают системный пробел.

| Как написал | Как лучше | Тип | Сколько раз повторилось | Последний раз | Статус |
|---|---|---|---:|---|---|
| `in USA` | `in the USA` | article / fixed form |  |  |  |
| `I heard that is...` | `I've heard that it's...` | tense / clause structure |  |  |  |
| `interested to` | `interested in` | preposition |  |  |  |
| `it rain`, `my friend come`, `my brother forget` | `it rains`, `my friend comes`, `my brother forgets` | Present Simple / 3rd person singular | 3+ | 2026-08-26 | **Актуально** |
| `watch movie`, `have job`, `won million euros` | `watch a movie`, `have a job`, `won a million euros` | articles | 3+ | 2026-08-26 | **Актуально** |

## Новые наблюдения

Пока не считаем системными ошибками, но отслеживаем в следующих упражнениях:

- потеря отрицания при переводе: `If my friend come...` вместо `If my friend doesn't come...` — меняется смысл всего предложения;
- конструкции после глаголов: `internet stops work` → `the internet stops working`;
- естественность формулировок: `come there on foot` → `walk there`, `get salary in time` → `get paid on time`.

## Как использовать

- Ошибка встретилась один раз — обычно просто исправить и идти дальше.
- Ошибка повторилась 2–3 раза — занести сюда.
- Ошибка продолжает повторяться — поднять соответствующую тему в [плане тем](<01 — План тем.md>).
- Если конструкция несколько раз подряд используется правильно в свободном тексте — пометить как закрытую.

## Неестественные конструкции

Отдельно фиксировать фразы, которые грамматически понятны, но построены по русской модели.

| Моя версия | Естественнее | Что запомнить |
|---|---|---|
| `The best way that I see it...` | `The way I see it...` | учить chunk целиком |
| `One of the interesting way to me...` | `One option that interests me...` | не переводить конструкцию дословно |
| `come there on foot` | `walk there` | использовать обычный глагол движения вместо дословной конструкции |
| `get salary in time` | `get paid on time` | учить chunk `get paid on time` |
