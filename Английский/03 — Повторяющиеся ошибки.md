# Повторяющиеся ошибки

Здесь храним не все ошибки подряд, а только те, которые повторяются или показывают системный пробел.

| Как написал | Как лучше | Тип | Сколько раз повторилось | Последний раз | Статус |
|---|---|---|---:|---|---|
| `in USA` | `in the USA` | article / fixed form |  |  |  |
| `I heard that is...` | `I've heard that it's...` | tense / clause structure |  |  |  |
| `interested to` | `interested in` | preposition |  |  |  |
| `it rain`, `my friend come`, `my brother forget` | `it rains`, `my friend comes`, `my brother forgets` | Present Simple / 3rd person singular | 3+ | 2026-08-26 | **Актуально** |
| `watch movie`, `have job`, `won million euros`, `about desk`, `in large city` | `watch a movie`, `have a job`, `won a million euros`, `about the desk`, `in a large city` | articles | 5+ | 2026-08-30 | **Актуально** |
| `internet stops work`, `I prefer live...` | `the internet stops working`, `I prefer living...` | verb patterns / gerund | 2+ | 2026-08-30 | **Актуально** |
| `it is a lot of options` | `there are a lot of options` | `there is / there are` | 1 | 2026-08-30 | **Отслеживать** |

## Новые наблюдения

Пока не считаем системными ошибками, но отслеживаем в следующих упражнениях:

- потеря отрицания при переводе: `If my friend come...` вместо `If my friend doesn't come...` — меняется смысл всего предложения;
- согласование действий в одном предложении: `I come home, eating some food, and ... playing` → `I come home, eat something, and ... play`;
- сравнительные конструкции: `I would like to live in a large city than a small town` → `I would rather live in a large city than in a small town`;
- предлоги и управление: `solution of this problem` → `solution to this problem`;
- естественность формулировок и collocations: `after my work` → `after work`, `do coffee` → `make coffee`, `play to different games` → `play different games`, `find master` → `find someone to repair it / hire a repairman`.

## Приоритет после IELTS-диагностики — 2026-08-30

1. **Артикли с исчисляемыми существительными** — самая явно повторяющаяся проблема.
2. **Verb patterns** — автоматически выбирать `-ing` после конструкций вроде `prefer`, `stop` и не смешивать формы глагола в перечислении действий.
3. **Естественные chunks / collocations** — меньше дословного перевода с русского (`after work`, `make coffee`, `get paid on time`).
4. **`there is / there are`** для значения «есть / имеется».
5. **Предлоги и управление** — учить вместе со словом или chunk, а не отдельно.

## Как использовать

- Ошибка встретилась один раз — обычно просто исправить и идти дальше.
- Ошибка повторилась 2–3 раза — занести сюда.
- Ошибка продолжает повторяться — поднять соответствующую тему в [плане тем](<01 — План тем.md>).
- Если конструкция несколько раз подряд используется правильно в свободном тексте — пометить как закрытую.

## Неестественные конструкции

Отдельно фиксировать фразы, которые грамматически понятны, но построены по русской модели.

| Моя версия | Естественнее | Что запомнить |
|---|---|---|
| `The best way that I see it...` | `The way I see it...` | учить chunk целиком |
| `One of the interesting way to me...` | `One option that interests me...` | не переводить конструкцию дословно |
| `come there on foot` | `walk there` | использовать обычный глагол движения вместо дословной конструкции |
| `get salary in time` | `get paid on time` | учить chunk `get paid on time` |
| `after my work` | `after work` | фиксированная естественная конструкция |
| `do coffee` | `make coffee` | collocation: `make coffee` |
| `play to different games` | `play different games` / `play games with my friends` | `play + game`, `with + person` |
| `find master` | `find someone to repair it` / `hire a repairman` | не калькировать русское «найти мастера» |
| `make delivery to apartment` | `have it delivered to the apartment` | chunk `have something delivered` |
