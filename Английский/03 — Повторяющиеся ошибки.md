# Повторяющиеся ошибки

Здесь храним не все ошибки подряд, а только те, которые повторяются или показывают системный пробел.

| Как написал | Как лучше | Тип | Сколько раз повторилось | Последний раз | Статус |
|---|---|---|---:|---|---|
| `in USA` | `in the USA` | article / fixed form |  |  |  |
| `I heard that is...` | `I've heard that it's...` | tense / clause structure |  |  |  |
| `interested to` | `interested in` | preposition |  |  |  |
|  |  |  |  |  |  |

## Как использовать

- Ошибка встретилась один раз — обычно просто исправить и идти дальше.
- Ошибка повторилась 2–3 раза — занести сюда.
- Ошибка продолжает повторяться — поднять соответствующую тему в [[01 — План тем]].
- Если конструкция несколько раз подряд используется правильно в свободном тексте — пометить как закрытую.

## Неестественные конструкции

Отдельно фиксировать фразы, которые грамматически понятны, но построены по русской модели.

| Моя версия | Естественнее | Что запомнить |
|---|---|---|
| `The best way that I see it...` | `The way I see it...` | учить chunk целиком |
| `One of the interesting way to me...` | `One option that interests me...` | не переводить конструкцию дословно |
|  |  |  |
