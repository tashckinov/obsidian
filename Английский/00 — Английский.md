# Английский

Текущая примерная точка: **A2+ / B1-**, цель — сделать B1 устойчивым и двигаться к B2.

## Как учиться

Цикл для каждой темы:

1. Открыть тему в [[01 — План тем]].
2. Перейти по ссылке на промпт в [[02 — Промпты для изучения]].
3. Отправить промпт ChatGPT и пройти материал + упражнения.
4. Записать результат и собственную оценку в таблицу.
5. Через несколько дней проверить тему в свободном тексте через [[04 — Письменная практика]].
6. Повторяющиеся ошибки заносить в [[03 — Повторяющиеся ошибки]].

Главная идея: тема считается усвоенной не тогда, когда упражнения решаются по подсказке, а когда конструкция правильно появляется в обычной речи или письме без напоминания.

## Навигация

- [[01 — План тем]] — основная таблица обучения
- [[02 — Промпты для изучения]] — готовые промпты для ChatGPT
- [[03 — Повторяющиеся ошибки]] — личные систематические ошибки
- [[04 — Письменная практика]] — проверка знаний в свободном тексте

## Правило оценки

- **0–3/10** — тему практически не понимаю
- **4–5/10** — понимаю объяснение, но ошибаюсь без подсказки
- **6–7/10** — в упражнениях нормально, в свободной речи нестабильно
- **8–9/10** — обычно использую правильно самостоятельно
- **10/10** — конструкция автоматическая
