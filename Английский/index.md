# Английский

Текущая примерная точка: **A2+ / B1-**, цель — сделать B1 устойчивым и двигаться к B2.

## Как учиться

Цикл для каждой темы:

1. Открыть тему в [плане тем](<01 — План тем.md>).
2. Перейти к [промпту для изучения](<02 — Промпты для изучения.md>).
3. Отправить промпт ChatGPT и пройти материал + упражнения.
4. Записать результат и собственную оценку в таблицу.
5. Через несколько дней проверить тему в свободном тексте через [письменную практику](<04 — Письменная практика.md>).
6. Повторяющиеся ошибки заносить в [журнал ошибок](<03 — Повторяющиеся ошибки.md>).

Главная идея: тема считается усвоенной не тогда, когда упражнения решаются по подсказке, а когда конструкция правильно появляется в обычной речи или письме без напоминания.

## Навигация

- [План тем](<01 — План тем.md>) — основная таблица обучения
- [Промпты для изучения](<02 — Промпты для изучения.md>) — готовые промпты для ChatGPT
- [Повторяющиеся ошибки](<03 — Повторяющиеся ошибки.md>) — личные систематические ошибки
- [Письменная практика](<04 — Письменная практика.md>) — проверка знаний в свободном тексте

## Правило оценки

- **0–3/10** — тему практически не понимаю
- **4–5/10** — понимаю объяснение, но ошибаюсь без подсказки
- **6–7/10** — в упражнениях нормально, в свободной речи нестабильно
- **8–9/10** — обычно использую правильно самостоятельно
- **10/10** — конструкция автоматическая
